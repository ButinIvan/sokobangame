# Склад 17 — Sokoban

Играбельный прототип классической головоломки Sokoban. В репозитории находятся две реализации: исходная версия на HTML/CSS/JavaScript и гибридная версия на Blazor, C# и JavaScript. В обеих есть кампания из 10 уровней и бесконечный режим со случайными гарантированно решаемыми расстановками.

## Запуск

Откройте `index.html` в любом современном браузере. Установка зависимостей и сервер не требуются.

### Docker Compose

```bash
docker compose up --build -d
```

После сборки доступны обе версии:

- классическая веб-версия: <http://localhost:8080>;
- Blazor-версия: <http://localhost:8081>.

Остановить контейнер:

```bash
docker compose down
```

Для запуска без Compose:

```bash
docker build -t sokoban-game .
docker run --rm -p 8080:80 sokoban-game
```

### Blazor без Docker

Для запуска требуется .NET 8 SDK:

```bash
dotnet run --project Sokoban.Blazor
```

Адрес приложения будет указан в терминале после запуска.

## Архитектура Blazor-версии

C# отвечает за каталог уровней, разбор карт и генерацию случайных решаемых расстановок. Razor-компоненты формируют интерфейс и передают игровые состояния через JS interop. JavaScript обрабатывает движение, толкание ящиков, историю ходов, звук и сенсорное управление.

## Управление

- Стрелки или `WASD` — движение
- `Z` — отменить последний ход
- `R` — перезапустить уровень
- На сенсорном экране доступны свайпы и экранные кнопки

Цель игры — передвинуть все ящики на отмеченные места. Ящики можно только толкать, но нельзя тянуть.
