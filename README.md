# Склад 17 — Sokoban

Небольшой играбельный прототип классической головоломки Sokoban на чистых HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в любом современном браузере. Установка зависимостей и сервер не требуются.

## Управление

- Стрелки или `WASD` — движение
- `Z` — отменить последний ход
- `R` — перезапустить уровень
- На сенсорном экране доступны свайпы и экранные кнопки

Цель игры — передвинуть все ящики на отмеченные места. Ящики можно только толкать, но нельзя тянуть.
